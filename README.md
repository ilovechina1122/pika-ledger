# 皮卡记账 🐕

一款可爱风格的桌面记账 APP，名字来自家里的小土狗「皮卡」。
支持 Windows 与 macOS（当前先交付 Windows 版）。

## ✨ 功能

- **记一笔**：金额、支出/收入、两级分类（先选大类再选小类）、日期、备注
- **账单**：按日期分组，支持类型/日期/分类/备注筛选，可编辑、删除
- **统计**：月度收入/支出/结余卡片、分类占比饼图（可点击下钻）、每日收支柱状图、近 12 个月趋势、分类排行
- **分类管理**：内置 16 个一级分类、53 个二级小类；支持自定义增删改、删除可恢复
- **数据安全**：本地 SQLite 存储，无需注册登录；每天自动备份（保留最近 30 份）

## 📦 安装（Windows）

**方式一：安装包（推荐）**
1. 双击 `pika-ledger-1.0.0-setup.exe`，按提示安装
2. 若弹出蓝色「Windows 已保护你的电脑」提示：点「更多信息」→「仍要运行」（这是未签名软件的常见提示，本软件安全）
3. 安装完成后桌面出现黄色小狗图标，双击即可记账

**方式二：免安装便携版**
1. 解压 `pika-ledger-1.0.0-portable.zip`
2. 双击文件夹里的「皮卡记账.exe」直接使用

## 🔒 数据说明

- 数据保存在（无需操心，软件自动管理）：
  - Windows：`C:\Users\<用户名>\AppData\Roaming\pika-ledger`
  - 里面有 `ledger.db`（账本）和 `backups`（每日自动备份，保留 30 份）
- **卸载软件不会删除数据**，重装后账目仍在
- **手动备份**：复制上面整个文件夹到 U 盘即可；恢复时把文件夹复制回来

## ⌨️ 开发者

```bash
npm install       # 安装依赖（已配置国内镜像）
npm run dev       # 开发模式
npm run build:win # 打包 Windows 安装包
```

- 技术栈：Electron + Vue 3 + Vite + TypeScript + SQLite + ECharts
- 维护提示：升级 Electron 或 better-sqlite3 后，需执行 `npm run rebuild` 重新适配原生模块

## 🍎 macOS

代码已天然兼容 macOS，安装包后续生成。届时使用 `npm run build:mac`（需在 Mac 上执行）。
